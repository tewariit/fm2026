# สร้างแทคติกเองทีละขั้น

> เวอร์ชันเกม: FM26 (อ้างอิงถึงแพตช์ 26.3) · อัปเดต: 2026-10-01 · ระดับ: มือใหม่–กลาง

## สรุปสั้น (TL;DR)
1. เลือกแผนตอนมีบอล (IP) ให้เข้ากับจุดแข็งของทีม
2. เลือกแผนตอนไม่มีบอล (OOP) จะเหมือนหรือต่างก็ได้ เช่น รุก 4-3-3 รับ 4-1-4-1
3. ตั้งบทบาทนักเตะทั้งสองเฟส
4. ตั้งคำสั่งทีม (Team Instructions) แยกตามเฟสและโซนสนาม
5. เลือกแนวทางการเล่น (Mentality) และเปลี่ยนตามสถานการณ์ในเกม

## คำสั่งทีมตอนมีบอล 3 ช่วง
| ช่วง | คำถามที่ต้องตอบ |
|---|---|
| เริ่มเกมจากแดนหลัง (Buildup) | ต่อบอลสั้นผ่านการเพรส หรือเล่นยาวข้ามแดน? |
| พาบอลผ่านกลางสนาม (Progression) | เน้นเล่นริมเส้นหรือตรงกลาง? จังหวะเร็วหรือช้า? |
| แดนสุดท้าย (Final Third) | สร้างโอกาสแบบไหน: เปิดบอล ยิงไกล หรือวิ่งทะลุช่อง? |

ตัวปรับหลัก: ความตรงของการจ่ายบอล (Passing Directness), จังหวะเกม (Tempo), ความกว้าง (Width), อิสระในการสร้างสรรค์ (Creative Freedom)

## แนวทางการเล่น (Mentality) 7 ระดับ
| ระดับ | ใช้เมื่อ |
|---|---|
| รับสุดตัว / รับ (Very Defensive / Defensive) | รักษาสกอร์ เยือนทีมที่แกร่งกว่ามาก หรือตั้งรับแล้วสวนกลับ |
| ระมัดระวัง (Cautious) | นำอยู่และอยากคุมเกม |
| สมดุล (Balanced) | ค่าเริ่มต้นที่ปลอดภัย |
| บุก (Positive) | เล่นในบ้านกับทีมที่อ่อนกว่า หรือตามหลัง (ระวังพื้นที่หลังฟูลแบ็ก) |
| รุก / รุกสุดตัว (Attacking / Very Attacking) | ไล่ตีเสมอ ใช้รุกสุดตัวเฉพาะ 10–15 นาทีสุดท้าย |

## หลักสำคัญ
- **อย่าตั้งแนวทางการเล่นไว้แล้วปล่อยทั้งเกม** เริ่มที่สมดุลหรือบุก นำแล้วลดเป็นระมัดระวัง ตามหลังแล้วเพิ่มเป็นรุก
- ⚠️ ชื่อแนวทางการเล่นภาษาไทยเป็นการแปลของคลังนี้ ในเกมใช้ชื่ออังกฤษ
