# วิเคราะห์คู่แข่งและ Data Hub

> เวอร์ชันเกม: FM26 (อ้างอิงถึงแพตช์ 26.3) · อัปเดต: 2026-10-01 · ระดับ: กลาง

## สรุปสั้น (TL;DR)
- ก่อนแข่ง เปิด **รายงานคู่แข่ง (Opposition Report)** ก่อนแก้แทคติกทุกครั้ง
- ปรับแทคติก **ทีละ 1 อย่าง** ที่มีเหตุผลรองรับ ไม่ต้องแก้ทั้งหมด
- ใช้ **Data Hub** ดูรูปแบบที่เกิดซ้ำของทีมตัวเองตลอดฤดูกาล

## รายงานคู่แข่งบอกอะไร
- แผนและสไตล์ที่คาดว่าจะใช้
- พื้นที่อันตราย ตำแหน่งที่ยิงประตูและแอสซิสต์
- จุดแข็งและจุดอ่อน และตัวอันตรายหลัก

## Data Hub ดูอะไร
| ข้อมูล | ใช้ทำอะไร |
|---|---|
| ตำแหน่งที่ยิงประตู/ยิงบอล | รู้ว่าทีมสร้างโอกาสจากตรงไหน |
| โอกาสที่สร้างได้ (Chances Created) | วัดคุณภาพเกมรุก |
| ความได้เปรียบในพื้นที่ (Pitch Tilt) | ใครคุมพื้นที่สุดท้ายของสนามได้มากกว่า |
| ช่วงเวลาที่ได้/เสียประตู | ปรับการเปลี่ยนตัวหรือความฟิต |
| การกระจายการเปิดบอล | ดูว่าเปิดจากฝั่งไหนบ่อย |
| แผนที่เจอ (Formations Faced) | หาว่าเจอแผนไหนแล้วทีมเรามักเล่นไม่ออก |

## ขั้นตอนทำในเกม
1. สั่งสเกาต์ไปดูคู่แข่งนัดถัดไป (Next Opposition Scouting)
2. ก่อนวันแข่งเช็กว่านักเตะคนไหนพร้อมลงสนาม และใครคือตัวอันตรายของคู่แข่ง
3. เลือกปรับ 1 อย่าง เช่น เพรสตัวสร้างเกมของคู่แข่ง หรือเปลี่ยนฝั่งที่เปิดบอล
4. หลังแข่ง ดูไฮไลต์กับ Data Hub ว่าการปรับนั้นได้ผลไหม
