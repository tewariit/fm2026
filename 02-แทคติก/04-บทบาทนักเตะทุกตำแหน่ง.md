# บทบาทนักเตะ (Player Roles) ทุกตำแหน่ง

> เวอร์ชันเกม: FM26 (อ้างอิงถึงแพตช์ 26.3) · อัปเดต: 2026-10-01 · ระดับ: กลาง

## สรุปสั้น (TL;DR)
- FM26 แยกบทบาทนักเตะแต่ละคนเป็น **2 ช่อง**: บทบาทตอนมีบอล (In Possession: IP) และตอนไม่มีบอล (Out of Possession: OOP)
- มีบทบาทใหม่หลายตัว (ติด 🆕) ที่ไม่มีใน FM24

## ผู้รักษาประตู (Goalkeeper)
| บทบาท | หน้าที่ |
|---|---|
| ผู้รักษาประตู (Goalkeeper) | สมดุล เล่นพื้นฐาน |
| 🆕 ผู้รักษาประตูยืนเส้น (Line-Holding Keeper) | อยู่ในกรอบเขตโทษ ไม่ออกนอกกรอบ |
| 🆕 ผู้รักษาประตูเล่นง่าย (No-Nonsense GK) | เล่นปลอดภัย ไม่เสี่ยง |
| สวีปเปอร์คีปเปอร์ (Sweeper Keeper) | ออกมาตัดบอลด้านหลังแนวรับ |
| ผู้รักษาประตูเล่นบอลเท้า (Ball-Player GK) | ร่วมเกมเหมือนเพลย์เมกเกอร์ |

## ฟูลแบ็ก (Full-Back)
| บทบาท | หน้าที่ |
|---|---|
| ฟูลแบ็ก (Full-Back) | สมดุล |
| 🆕 ฟูลแบ็กคุมหลัง (Holding Full-Back) | ยืนคุมไว้กันการโต้กลับ |
| 🆕 ฟูลแบ็กหุบใน (Inside Full-Back) | หุบเข้ามาเป็นเซ็นเตอร์แบ็กคนที่ 3 |
| ฟูลแบ็กตัดเข้ากลาง (Inverted Full-Back) | ดันขึ้นและเข้ามาตรงกลางสนาม |
| 🆕 ฟูลแบ็กเพรสซิ่ง (Pressing Full-Back) | ช่วยเพรสสูง |
| วิงแบ็กเติมเกมรุก (Advanced Wing-Back) | ขึ้นไปยืนเหมือนปีก เป็นตัวรุกเพิ่ม |

## เซ็นเตอร์แบ็ก (Centre-Back)
| บทบาท | หน้าที่ |
|---|---|
| เซ็นเตอร์แบ็ก (Centre-Back) | สมดุล |
| เซ็นเตอร์แบ็กดันขึ้น (Advanced Centre-Back) | ขึ้นไปยืนตำแหน่งกองกลางตัวรับ |
| เซ็นเตอร์แบ็กเล่นบอล (Ball-Playing CB) | จ่ายบอลทะลุแนว |
| เซ็นเตอร์แบ็กเล่นง่าย (No-Nonsense CB) | ยืนตำแหน่ง ลดความเสี่ยง |
| เซ็นเตอร์แบ็กริมเส้น (Wide Centre-Back) | ใช้ในแผน 3 เซ็นเตอร์ ออกไปช่วยด้านข้าง |
| 🆕 เซ็นเตอร์แบ็กวิ่งซ้อนเติม (Overlapping CB) | ผสมหน้าที่เซ็นเตอร์แบ็กกับปีก |

## กองกลาง (Midfield)
| บทบาท | หน้าที่ |
|---|---|
| กองกลาง (Central Midfielder) | สมดุล |
| 🆕 กองกลางกันพื้นที่ (Screening CM) | ปิดพื้นที่ตรงกลางหน้าแนวรับ |
| 🆕 กองกลางคุมด้านข้าง (Wide-Covering CM) | ขยับออกข้างช่วยเกมรับ |
| บ็อกซ์ทูบ็อกซ์ (Box-to-Box) | วิ่งทั้งสนาม |
| 🆕 บ็อกซ์ทูบ็อกซ์เพลย์เมกเกอร์ (Box-to-Box Playmaker) | วิ่งทั้งสนามและสร้างสรรค์เกม |
| กองกลางวิ่งช่อง (Channel Midfielder) | วิ่งเข้าช่องว่างหลังแนวรับคู่แข่ง |
| เพลย์เมกเกอร์ (Midfield Playmaker) | เชื่อมเกมจากแนวรับไปแนวรุก |

### บทบาทตอนมีบอลที่ตำแหน่ง M(C) (ยืนยันจากหน้าจอเกมจริง)
| บทบาท | คำอธิบายในเกม |
|---|---|
| Central Midfielder | สมดุล |
| Attacking Midfielder | หาช่องว่างระหว่างแนว / ภัยคุกคามจากประตู |
| Advanced Playmaker | หาช่องว่างระหว่างแนว / แสดงออก |
| Wide Central Midfielder | เลี้ยงบอลออกข้าง |
| Channel Midfielder | วิ่งหาช่อง / สร้างสรรค์เกมรุก |
| Midfield Playmaker | แสดงออก / สร้างสรรค์เกมรุก |

- **Deep-Lying Playmaker (DLP) ไม่มีในตำแหน่ง M(C)** ต้องวางนักเตะไว้แถว DM ถึงจะเลือกได้
- ตอนตั้งบทบาท เลือก **"ส่วนบุคคล"** เพื่อให้บทบาทนั้นใช้กับนักเตะคนนี้คนเดียว ถ้าเลือก **"ตำแหน่ง"** ใครลงตำแหน่งนี้ก็ได้บทบาทเดียวกันหมด

## กองกลางริมเส้นและแนวรุก (Wide / Attack)
| บทบาท | หน้าที่ |
|---|---|
| กองกลางริมเส้น (Wide Midfielder) | ยืนต่ำ เปิดบอล |
| 🆕 กองกลางริมเส้นไล่กลับ (Tracking Wide Midfielder) | ถอยลงมาช่วยรับ |
| 🆕 กองกลางริมเส้นหุบกลาง (Wide Central Midfielder) | ช่วยสร้างเกม |
| 🆕 ตัวเป้าริมเส้น (Wide Outlet Midfielder) | ยืนสูง รอรับบอลตอนโต้กลับ |
| 🆕 กองหน้าริมเส้น (Wide Forward) | กองหน้าที่เล่นริมเส้น |
| 🆕 กองหน้าวิ่งช่อง (Channel Forward) | วิ่งช่องระหว่างฟูลแบ็กกับเซ็นเตอร์แบ็ก |

## ข้อควรระวัง
- ⚠️ ชื่อภาษาไทยในตารางเป็นการแปลของคลังนี้ ไม่ใช่ชื่อในเกม ให้ใช้ชื่ออังกฤษเวลาค้นหาในเกม
- รายชื่อนี้ยังไม่ครบทุกบทบาท ดูฉบับเต็มจากลิงก์ด้านล่าง
