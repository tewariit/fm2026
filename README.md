# FM Guru — คลังความรู้พิชิต Football Manager 2026

คู่มือ เทคนิค และบันทึกการเล่น FM26 จัดเป็นไฟล์ Markdown แยกตามหมวด

| โฟลเดอร์ | เนื้อหา |
|---|---|
| 01-พื้นฐาน | เริ่มเกม, UI, สิ่งที่เปลี่ยนจาก FM24 |
| 02-แทคติก | ระบบการเล่น, บทบาทผู้เล่น, แทคติกสำเร็จรูป |
| 03-การซื้อขายนักเตะ | สเกาต์, ต่อรอง, สัญญา, นักเตะราคาถูก |
| 04-ดาวรุ่งและเยาวชน | Wonderkids, การพัฒนา, ยืมตัว |
| 05-การฝึกซ้อม | ตารางซ้อม, ความฟิต, การป้องกันเจ็บ |
| 06-การเงินและบอร์ด | งบประมาณ, เป้าหมายบอร์ด, ไดนามิก |
| 07-ทีมแนะนำ-Save | ทีมน่าคุมและไกด์เซฟ |
| 08-เทคนิคลับและบั๊ก | ทริก, ข้อควรระวัง, แพตช์ |
| _templates | เทมเพลตสำหรับเขียนบทความใหม่ |
| sources | ลิงก์แหล่งอ้างอิง |

## หลักการเขียน
- ทุกบทความระบุ **เวอร์ชันเกม/แพตช์** ที่ทดสอบ
- ข้อมูลที่ยังไม่ยืนยัน ให้ติดป้าย `⚠️ ยังไม่ยืนยัน`
- อ้างอิงแหล่งที่มาใน `sources/`
