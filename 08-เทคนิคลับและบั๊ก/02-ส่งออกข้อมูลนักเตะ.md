# ส่งออกข้อมูลนักเตะ (Export) เป็นไฟล์

> เวอร์ชันเกม: FM26 (อ้างอิงถึงแพตช์ 26.3) · อัปเดต: 2026-10-01 · ระดับ: กลาง

## สรุปสั้น (TL;DR)
- ในเกมมี **Print Screen** ส่งออกหน้ารายชื่อเป็นไฟล์ HTML ได้ แต่จะได้เฉพาะคอลัมน์ที่เปิดแสดงอยู่บนหน้าจอ
- ถ้าอยากได้ CSV ทั้งรายการ ใช้ปลั๊กอิน **FM26 Player Export** ซึ่งเป็นม็อดของชุมชน ไม่ใช่ของทางการ

## วิธีที่ 1: Print Screen ในเกม
1. เปิดหน้ารายชื่อ เช่น ทีมชุดใหญ่ ผลค้นหา หรือ Shortlist
2. ตั้งมุมมองให้แสดงคอลัมน์ที่ต้องการ เช่น ค่าพลังทั้งหมด
3. เปิดเมนูดรอปดาวน์ของหน้านั้น → Print Screen → บันทึกเป็นหน้าเว็บ (Web Page)
4. ไฟล์จะอยู่ใน `Documents\Sports Interactive\Football Manager 2026`
- Mac: ⌘+A เลือกทุกแถว → ⌘+P → เลือก Web Page
- ⚠️ ในช่วงเบต้ามีรายงานว่าฟีเจอร์นี้ใช้ไม่ได้ ถ้าเจอปัญหาให้ลองอัปเดตเกมเป็นแพตช์ล่าสุด

## วิธีที่ 2: ปลั๊กอิน FM26 Player Export
- ติดตั้งผ่าน BepInEx แล้วกด Ctrl+P ปลั๊กอินจะเลื่อนดูทั้งรายการเองและส่งออกเป็น CSV + HTML
- ⚠️ เป็นม็อดภายนอก ใช้แล้วอาจทำให้เกมเสียหายหลังอัปเดตแพตช์ ดาวน์โหลดจากแหล่งที่ระบุเท่านั้น

## ใช้กับคลังนี้
วางไฟล์ HTML/CSV ไว้ที่โฟลเดอร์ `exports/` ของโปรเจกต์ แล้วให้ Claude วิเคราะห์ทีม หาบทบาทที่เหมาะ หรือคัดนักเตะเป้าหมาย
