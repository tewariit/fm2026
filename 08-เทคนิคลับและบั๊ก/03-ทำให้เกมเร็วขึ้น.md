# ทำให้เกมเร็วขึ้น

> เวอร์ชันเกม: FM26 (อ้างอิงถึงแพตช์ 26.3) · อัปเดต: 2026-10-01 · ระดับ: ทุกระดับ

## สรุปสั้น (TL;DR)
- ลดจำนวนลีกที่โหลด และ **ปิดลีกหญิง** ถ้าไม่ได้เล่น (ตั้ง League Selector เป็น None ทุกประเทศ)
- ตั้งความเร็วการประมวลผลแมตช์ของทีมอื่นเป็น **เร็ว (Fast)**
- เปิด **Continue Game Timeout** ให้เกมกดดำเนินการต่อเอง ช่วยให้จบฤดูกาลเร็วขึ้นได้เกือบครึ่ง
- ลดกราฟิกในแมตช์ถ้าเครื่องสเปกต่ำ

## การตั้งค่า (Preferences)
| ส่วน | ปรับอะไร |
|---|---|
| ความเร็วแมตช์ | เพิ่มความเร็วช่วงระหว่างไฮไลต์ |
| กราฟิก | ลดลงเพื่อให้ภาพลื่น |
| การประมวลผล (Processing) | ให้เกมหยุดน้อยลง และจำกัดวันแข่งเป็นวันอาทิตย์/พุธ |
| ข่าว | ติดตามข่าวน้อยลงเพื่อลดภาระการประมวลผล |

## ข้อควรระวัง
- การตั้งค่าเหล่านี้ไม่มีผลกับผลการแข่ง มีผลแค่ความเร็วและความลื่นของเกม
- ⚠️ ลีกที่ปิดตอนเริ่มเซฟ เปิดภายหลังได้จำกัด ควรเลือกให้ครบตั้งแต่ต้น
