# บุคลิกนักเตะ (Personality) และค่าพลังแฝง

> เวอร์ชันเกม: FM26 (อ้างอิงถึงแพตช์ 26.3) · อัปเดต: 2026-10-01 · ระดับ: กลาง

## สรุปสั้น (TL;DR)
- บุคลิก **เป็นตัวคูณการพัฒนา**: ศักยภาพเท่ากัน แต่บุคลิกดีจะพัฒนาถึงศักยภาพได้มากกว่า
- **ความเป็นมืออาชีพ (Professionalism)** เป็นค่าพลังแฝงที่สำคัญที่สุด มีผลต่อความเร็วในการพัฒนา วินัยการซ้อม และการรับมือกับช่วงตกต่ำ
- **นัดสำคัญ (Important Matches)** กำหนดว่านักเตะจะเล่นดีหรือแย่ในนัดชี้ขาด

## บุคลิกที่ดีที่สุดสำหรับการพัฒนา
| บุคลิก | จุดเด่น |
|---|---|
| Model Citizen | Professionalism สูง + Pressure, Loyalty, Sportsmanship, Temperament สูง |
| Model Professional | Professionalism สูงมาก |
| Perfectionist | Professionalism สูง |
| Resolute | Professionalism สูง รับมือกับความกดดันดี |
| Professional | Professionalism สูง |

## บุคลิกที่ดีรองลงมา
- **Resilient**: ฟอร์มไม่ตกในนัดใหญ่ ไปถูกยืมตัวที่ไหนก็ปรับตัวได้เร็ว
- **Light Hearted**: เหมือน Resilient แต่เข้ากับเพื่อนร่วมทีมได้ดี ไม่ค่อยมีเรื่องกับใคร

## ใช้อย่างไร
- ตอนสเกาต์ดาวรุ่ง ให้ดูบุคลิกด้วย ไม่ใช่ดูแค่ศักยภาพ
- ดาวรุ่งที่บุคลิกไม่ดี ให้อยู่กลุ่มพี่เลี้ยง (Mentoring) กับนักเตะที่บุคลิกดี
